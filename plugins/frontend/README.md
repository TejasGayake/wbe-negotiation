# Frontend Dev Plugin

Scaffold for frontend/UI development work. Intended to hold:
- Tailwind CSS config + component patterns
- shadcn/ui / Radix primitives
- Animation helpers (see `animate` skill)
- Mobile-native fixes (see `mobile-native` skill)

Install the skills you plan to use first, then point this plugin at them.

## Suggested skills
- `ui-styling`, `design-taste-frontend`, `minimalist-ui`
- `animate`, `apple-design`, `mobile-native`, `slides`
