# Backend Dev Plugin

Scaffold for backend development work. Intended to hold:
- Python/FastAPI/Flask service patterns
- SQL schema + query helpers (see `sql-pro` skill)
- Auth/JWT + input validation (see `secure-code-guardian` skill)
- API design (OpenAPI) (see `api-designer` skill)

## Suggested skills
- `python-pro`, `sql-pro`, `secure-code-guardian`, `api-designer`
- `rag-architect`, `test-master`, `prompt-engineer`
