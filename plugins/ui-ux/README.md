# UI/UX Dev Plugin

Scaffold for UI/UX design work. Intended to hold:
- Design tokens + component specs
- Layout patterns (bento grids, editorial, minimalist)
- Motion / animation guidelines
- Accessibility checks

## Suggested skills
- `ui-styling`, `design-taste-frontend`, `minimalist-ui`, `industrial-brutalist-ui`
- `animate`, `apple-design`, `mobile-native`, `high-end-visual-design`
- `brand`, `slides`
